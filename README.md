# Portfolio Project

This is a portfolio website where I will showcase my projects I have been working on,
and the skills I have acquired. 
I used React + Vite, a component library called react bits
(this is where the silk.jsx, glassicons.jsx, and SpotlightCard.jsx components come from.),
I also used Tailwindcss for my styling.

The Silk background renders at 30 frames per second and 75% resolution to
reduce GPU usage. Its animation pauses when it is off-screen, the tab is hidden,
or reduced motion is enabled; on narrow screens the background is hidden.
